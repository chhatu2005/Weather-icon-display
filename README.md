# 🌦️ Weather Icon Display

## 📌 Project Overview
Weather Icon Display is a simple and responsive web application built using HTML, CSS, and JavaScript. It allows users to select different weather conditions and view the corresponding weather icon, description, and background color.

This project uses static data and does not require any weather API.

## ✨ Features
- 🌞 Displays six weather conditions: Sunny, Cloudy, Rainy, Snowy, Stormy, and Windy.
- 🎨 Displays a matching icon and background color for each condition.
- 📝 Shows a description of the selected weather condition.
- 🔄 Updates the display dynamically when the user changes the selection.
- 📱 Responsive design for mobile and desktop screens.
- ⚡ Simple and user-friendly interface.
- 🔌 No API required.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Select a weather condition from the dropdown menu.
5. View the corresponding icon, description, and background color.
